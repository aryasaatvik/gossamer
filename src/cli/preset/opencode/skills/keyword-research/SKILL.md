# Keyword Research

Use PageGraph's route and page evidence as the ownership baseline. Read
[Executor Starters](references/executor.md) before collecting live evidence.

Start from the supplied seeds and consumer product context. Expand only into queries that match the
actual product, audience, and market. Use owned-site performance to establish current visibility,
provider metrics to estimate demand and competition, and current SERPs to validate intent. A volume
estimate alone does not establish product fit or justify a new page.

Map each supported query to the strongest existing page. Propose a new page only when no current
page can satisfy the distinct intent without becoming unfocused. Preserve evidence and caveats for
every opportunity.

Return the structured state requested by the workflow. Do not save keywords, update provider
projects, submit URLs, or edit repository files during research.
