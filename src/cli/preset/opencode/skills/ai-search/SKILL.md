# AI Search Analysis

Start from the page's visible content, structured data, route context, and cited sources. Read
[Executor Starters](references/executor.md) before collecting current AI-search observations.

Evaluate whether an answer engine can identify the subject, extract a concise answer, understand
entity relationships, and trace material claims to first-party or trustworthy support. Distinguish
observed citations from inferred readiness. Do not claim a visibility lift from formatting alone.

Return the structured state requested by the workflow. This workflow produces evidence and a
diagnosis; it does not edit pages or submit them to an answer engine.
