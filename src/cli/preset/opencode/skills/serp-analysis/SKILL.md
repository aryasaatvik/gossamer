# SERP Analysis

Treat each supplied query, market, language, device, and target page as one analysis unit. Read
[Executor Starters](references/executor.md) before fetching current result evidence.

Identify dominant intent, page format, result features, recurring domains, title framing, and the
evidence a useful page must satisfy. Compare the target against those patterns without turning
competitor wording into product truth. Mark mixed or unstable intent rather than forcing a single
conclusion.

Return the structured state requested by the workflow. A current SERP is observed evidence for its
market and time, not a universal ranking rule.
