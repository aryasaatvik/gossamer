# Content Analysis

Start from the supplied source, rendered page, route relationships, and project truth. Read
[Executor Starters](references/executor.md) when live owned-site or competitive evidence is needed.

Judge whether the page answers its intended need, supports material claims, avoids sibling-page
cannibalization, and offers useful depth for its format. Use word counts and competitor excerpts as
descriptive signals, never as universal targets. Keep product accuracy ahead of search demand.

Return the structured state requested by the workflow. This workflow diagnoses content; it does not
edit source files.
