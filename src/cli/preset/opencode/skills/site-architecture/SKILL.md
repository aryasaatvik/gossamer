# Site Architecture

Use PageGraph's deterministic route nodes and edges as the primary model. Read
[Executor Starters](references/executor.md) when owned search or crawl evidence can resolve an
ownership or discoverability question.

Assign one clear intent owner, identify useful collections and parent-child relationships, and
prefer consolidation when multiple pages compete for the same need. Propose new routes only when a
distinct supported intent lacks an adequate owner. Treat URL changes as consequential and preserve
redirect and canonical requirements in the recommendation.

Return the structured state requested by the workflow. This planning workflow does not move routes,
edit navigation, or submit sitemaps.
