# Schema

Use the rendered page, existing JSON-LD, route kind, and owning source as the primary evidence. Read
[Executor Starters](references/executor.md) when owned search appearance or current eligibility
evidence is material.

Propose only types and properties that describe visible content. Schema does not repair missing
content, guarantee a rich result, or justify unsupported ratings, prices, authorship, FAQs, or
organization claims.

During the host-authorized action turn, apply only accepted changes through the repository's
existing JSON-LD composition primitives. Do not edit rendered or generated output. Leave the diff
uncommitted and provider state unchanged.
